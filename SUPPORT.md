# Soporte de Proyect X

Antes de abrir un issue, revisa el manual de configuración en el README y los límites de cobertura en `docs/FASES_PRODUCTO.md`.

Para errores de reglas o presupuestos, describe la versión, fabricante/modelo, versión de Android, permisos habilitados y pasos reproducibles. No incluyas URLs visitadas, texto de aplicaciones, registros de uso, nombres de cuenta ni capturas con datos personales.

Los bloqueos erróneos deben indicar solo el paquete de Android y si había una regla o presupuesto activo. Los informes de seguridad siguen el proceso privado de `SECURITY.md`.
