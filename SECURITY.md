# Seguridad de Proyect X

## Reportar una vulnerabilidad

No publiques detalles explotables ni datos personales en un issue público. Cuando el repositorio se publique en GitHub, utiliza **Security → Report a vulnerability** para enviar un aviso privado al mantenedor.

Incluye versión de la app, dispositivo/API Android, pasos de reproducción, impacto esperado y evidencia mínima. No adjuntes historial de navegación, URLs privadas, capturas con datos personales ni credenciales.

## Alcance actual

Se consideran dentro de alcance: permisos, componentes exportados, almacenamiento local, reglas, uso de Accesibilidad, Usage Access y futuros artefactos de política. No se promete resistencia frente a un dispositivo rooteado, ADB autorizado, restablecimiento, desinstalación o acceso físico de la persona propietaria.

La respuesta y corrección se gestionarán mediante un fix-forward o rollback documentado. Una clave de firma de release nunca debe entrar al repositorio.
